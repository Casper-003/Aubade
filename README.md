# Vesper

面向 Windows 的家庭 KTV 软件。目标是让选歌、排队和演唱自然连贯，同时认真打磨界面与操作反馈。

**当前阶段：产品设计与项目起步。仓库尚未包含可运行的应用工程。**

## 已确定的方向

- Windows 桌面应用，采用 C#、.NET、WinUI 3 与 MVVM。
- 首版以本地曲库为基础，手机通过局域网网页参与点歌，无需安装专用 App。
- 主界面采用左侧导航、中央曲目推荐、右侧默认收起的待播队列。
- 卡拉 OK 支持单屏视频全屏，以及双屏一屏演唱、一屏保持主界面。
- 歌词优先评估复用 Lyricify 已开源的 .NET 歌词工具库。
- 保留共享低延迟、独占、兼容共享三种可切换 WASAPI 模式；实际支持范围和延迟需要设备验证。

具体按钮位置、预览行为、队列排序与多人权限仍有讨论项。资料中的“已确认设计”不代表功能已实现。

## 讨论与交付方式

一次只讨论一个小问题或流程。明确确认后记录结论；设计、实现和验收分别标记。后续功能任务建议使用短期分支和 PR，通过可展示的结果交流进度。

两位协作者和多台电脑各自使用独立克隆。开工前检查 Git 状态与分支，收工前提交并推送；不要用共享网盘同步同一个 Git 工作目录。
