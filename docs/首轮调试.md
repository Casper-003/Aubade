# 主窗口首轮调试

日期：2026-10-29。当前只核对实际 WinUI 3 窗口，不制作静态视觉稿。

## 已运行的范围

- WinUI 3 主窗口，Mica 背景，跟随系统应用的浅色／深色主题。
- 一体式标题栏，左侧软件图标占位与 Vesper 名称；仅保留软件图标左侧的后退按钮，有可用后退历史时显示。2026-10-29 按用户最新决定移除前进按钮及对应逻辑。
- 导航展开宽度 220、折叠宽度 56；展开时图标加文字，折叠后仅图标；按钮在首页入口上方，设置固定在底部。
- 根据实际窗口反馈，后退图标采用 16 单位，按钮区域为 32；顶部演唱入口的位置变化使用 WinUI 原生 RepositionThemeTransition，动画体感仍待用户确认。
- 首次默认展开，记住上次折叠／展开状态；顶部演唱入口以扣除侧栏后的内容区居中。
- 设置页提供默认 Vesper Miku 蓝 `#39C5BB` 与跟随系统强调色两项；偏好保存在本机，不入库。

## 本轮边界

- 220／56 是已同意的起始宽度；标题栏和其他未定视觉尺寸、图标外观仍待用户在实际窗口中核对。
- 设置导航项显式显示中文“设置”。
- 废弃的旧功能壳源码已复制到本机忽略目录 `local-data/retired-prototype/` 供追溯，不作为新界面依据。

## 构建与运行

本机已使用 .NET SDK 10.0.403、Windows App SDK 1.8 构建并实际启动。首次编译需要恢复 NuGet 依赖。

```powershell
dotnet build src/Vesper.App/Vesper.App.csproj -c Debug -p:Platform=x64
& .\src\Vesper.App\bin\x64\Debug\net10.0-windows10.0.19041.0\win-x64\Vesper.App.exe
```

也可在 Visual Studio 打开 `Vesper.slnx`，使用 Vesper.App 的 Unpackaged、x64 启动配置。
