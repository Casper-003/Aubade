## 当前实现范围

- WinUI 3 主窗口，Mica 背景，跟随系统应用的浅色／深色主题。
- 页面容器背景改为透明，让窗口 Mica 透出；内容层沿用 NavigationView 自带的淡半透明底色，不再铺不透明页面背景或重复叠加底色。此页面材质方案于 2026-10-29 经用户确认，视觉效果待用户验收。
- 首页在没有可用歌曲时显示醒目的图形、28 单位标题、16 单位说明与分步导入指引，明确打开左侧“曲库”、点击右上角文件夹加号、选择本地歌曲或 MV 目录；不设置导入按钮。目录配置、歌曲记录和收藏保存在本机。
- 曲库常态只保留页面标题、歌曲列表与添加、目录管理、刷新三个图标入口，操作说明放在悬停提示。目录管理采用覆盖式弹出层，打开、关闭不推移歌曲列表；目录移除及可用状态也采用图标。
- 一体式标题栏左上角移除软件名称与 Logo，后退、前进按此顺序固定显示，不可用时禁用。按钮区域 48×36，箭头由 12 放大到与导航图标一致的 16 单位；保留原生 Frame 历史、页面过渡与官方 AnimatedBackVisualSource 的悬停和按压动效。
- 导航展开宽度 220、折叠宽度 56；展开时图标加文字，折叠后仅图标；按钮在首页入口上方，设置固定在底部。
- 顶部播放控件、占位框、居中和位移动画已全部移除，新的演唱入口待用户重新设计。
- 导航首次默认展开，记住上次折叠／展开状态。窗口最小尺寸先采用 900×600 个界面单位，随系统缩放换算为窗口像素，供用户检查后调整。
- 设置页提供强调色来源和“隐藏不可用歌曲”选项；隐藏选项不再常驻曲库页，并随偏好保存在本机，跨启动恢复，不入库。
- 设置上方的后台活动项沿用设置的导航项布局资源、字号、图标尺寸与前景色，忙碌槽改用原生 ProgressRing，完全移除旋转整张路径图标的代码。状态文字、图形及悬停内容每次至少保持一秒，频繁报告合并到最新快照，不积压旧状态。后台和前台操作保持原有响应。
- 内容层四角仍为 8 单位圆角，右侧与底部的 Mica 包边按用户最新要求收窄到 4 单位；保留目录弹出层的覆盖行为。
- MKV 画质通过 EBML 视频轨道元数据独立读取，处理裁剪和隔行标记；监听列表首次加载与容器复用的 DataContext 变化，避免漏读后续歌曲。非 MKV 使用 Windows 视频属性，未识别时不显示虚假标签。
- 扫描期间添加、目录管理、刷新继续可用；连续添加或移除目录会合并到最新任务，过期结果不能覆盖新配置。扫描改用文件信息预筛选与持久缓存，只完整核对可能重复的文件，刷新不清空整张列表。
- 收藏页沿用曲库歌曲行、心形与加号操作，按收藏时间倒序排列并跨启动保留；取消后重新收藏回到首位。两个页面共享画质、艺人与收藏状态，设置中的隐藏不可用规则同时生效。空状态区分尚未收藏与收藏暂不可用，普通列表不增加搜索或文字工具栏。
- 收藏操作结果与异常提示复用底部覆盖层，不推移页面。修复操作提示出现时误停状态仪表刷新计时器的问题，仪表计时仅在关闭窗口时停止。

## 构建与运行

本机已使用 .NET SDK 10.0.403、Windows App SDK 1.8 构建并实际启动。首次编译需要恢复 NuGet 依赖。

```powershell
dotnet build src/Vesper.App/Vesper.App.csproj -c Debug -p:Platform=x64
& .\src\Vesper.App\bin\x64\Debug\net10.0-windows10.0.19041.0\win-x64\Vesper.App.exe
```

也可在 Visual Studio 打开 `Vesper.slnx`，使用 Vesper.App 的 Unpackaged、x64 启动配置。
