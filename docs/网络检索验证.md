# 联网来源与验证

2026-10-29。用户将联网检索确定为核心能力，本记录区分已接入、真实实测及尚未覆盖的情况。

## 已接入来源

| 用途 | 来源 | 验证 |
| --- | --- | --- |
| 曲目、艺人、发行资料 | MusicBrainz | 真实查询成功，也观察过 503；不能把服务失败记成无曲目 |
| 曲目、专辑、封面 | 网易云音乐 | cloudsearch/pc 真实查询成功；旧 get/web 有返回加密字符串的情况，未采用其作为有效解析结果 |
| 曲目、艺人、专辑、封面 | Deezer | 真实查询成功，与中文来源互补 |
| 正文、逐行及来源已有的逐字原始资料 | LRCLIB | 真实歌词读取成功；遵守 Retry-After |
| LRC 歌词 | 网易云音乐 | 搜索后读取歌词成功，按来源时长保留兼容边界 |
| LRC 歌词 | 酷狗音乐 | 搜索、下载和解码成功；无艺人或时长核对依据时保守处理，不冒充同步验证 |

并行查询来源，复用网易歌曲搜索结果以服务资料与歌词；单个来源不可用时保留其他有效结果。自动匹配仍核对歌名和艺人，不按第一条搜索结果无条件绑定。用户修正优先，缓存保持实际来源。网络异常、无结果、歧义分别处理。

## 实际客户端样本

- “稻香”：MusicBrainz 返回 30 项发行候选，网易 12 项，Deezer 19 项；LRCLIB 20 项歌词候选、网易 3 项，正文可解析。酷狗该次未通过候选条件，没有作为有效命中统计。
- “真的爱你”：该次网易返回 10 项、Deezer 20 项；LRCLIB 返回 20 项歌词候选、网易 3 项、酷狗 2 项，正文可解析。MusicBrainz 该次未提供可用候选，不因此判定曲目无资料。
- 酷狗“稻香”的补充诊断：无时长条件时前列包含片段；带 223000 毫秒时长后能返回约 223 秒的候选。实现采用已有艺人辅助并优先常见完整时长，仍需实际音频版本核验。
- QQ 旧公开搜索本次返回 HTTP 500；Apple 中国区样本无结果。这些来源尚未加入正常获取路径，不以来源数量替代可用性验证。

这些数字是少量查询的当次响应，不是固定覆盖率；不将候选数当成有效匹配数，也不声称任意曲目都有逐字数据。

## 自动与人工检查

- 自动检查覆盖前两个资料源失败后 Deezer 接替、主歌词源失败后网易／酷狗接替、搜索请求复用、实际来源保留、缓存恢复及旧结果拒绝。
- 最新页头实现改为整宽图片横幅，高度为页面可用高度的 0.382；Favourites／Library 随滚动由 72 单位粗体连续缩至约 24 单位常规字重。采用合成线程滚动表达式、图片淡出、裁剪与两种字重交叉渐变，保留 48 单位主题底色小条。
- 删除每次 LayoutUpdated 遍历两个列表重设背景的实现，保留虚拟化；行底色只在容器准备、集合改变时设置，主题切换更新共享画刷。自定义圆角行模板不含整行悬停变色状态。列表仍限制 1120 单位宽度，实际滚动手感和浅深色效果由用户检查。
- 尚未完成系统化大样本覆盖统计、持续来源健康仪表、全部歌词格式与逐字渲染；当前单请求超时和既有缓存不能当成已达到长期服务可靠性的证明。
