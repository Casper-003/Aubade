# M02 本地曲库、搜索与详情

更新：2026-10-27。本地曲库与搜索方向已确认；具体交互讨论中，尚未实现。

## 已确认

- 首版以本地歌曲与 MV 为基础，支持歌名、歌手及拼音/首字母搜索。
- B 站 MV 接入保留为后续候选，尚未验证完整接入能力或纳入首版。

## 用户提案（未定稿）

- 列表左侧封面、歌名和作曲家信息；右侧加入队列、收藏、预览。
- 点击歌曲行空白处进入简洁详情页，可联网补充作曲家与专辑介绍。
- 同名曲目先按歌手分开列出，显示版本标签；封面悬停预览及迷你播放器归 M05。

## 助手建议（未确认）

- 列表优先显示歌名、歌手和版本，作词/作曲等放进详情。
- 封面、歌名与空白区域的点击应保持可预期；独立按钮执行各自操作，不误切当前演唱。
- 联网补充不阻塞本地浏览，资料缺失有简洁状态。

## 可讨论的小问题

歌曲行哪些区域进入详情，哪些区域执行独立操作？协作者可准备同名、不同版本、无封面、超长标题等虚拟样例。

范围：歌曲辨认、搜索、收藏与详情；加入后的队列规则归 M03，预览归 M05。
