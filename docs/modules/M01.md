# M01 主界面与首页导航

更新：2026-10-27。设计部分确认；尚未实现。

## 已确认

- 左侧功能栏竖向排列，中央为首页内容，右侧队列默认收起，可展开/收起。
- 软件左上角设置前进、后退控件，独立于左侧竖向功能列表。
- 浏览与远距离演唱分别考虑字号和信息密度。

### 顶部演唱入口

- 采用顶部居中的固定区域，将 MV 预览、开始演唱和返回演唱合为一个按钮。
- 没有正在演唱的歌曲且待播队列为空时，显示灰色 Logo，不可点击。
- 待播队列有歌曲且尚未开始演唱时，显示彩色 Logo；点击后按钮通过拉伸放大、展开的动画进入 KTV 模式。具体单/双屏呈现归 M04。
- 演唱中切回主界面选歌时，该区域显示当前 MV 的实时高斯模糊画面；点击即可返回演唱画面。
- 正在唱最后一首时，即使待播队列为空，也继续显示当前 MV，并保留返回演唱的入口。
- 三种状态均不配文字，保持整体简洁；不采用常驻“尚未点歌”“开始演唱”“返回演唱”等状态文案的建议。
- 草图中的专辑封面仅作为 MV 的占位素材，实际使用当前 MV。

### 首页内容

- 整体大方、简洁，保留充分留白。
- 首页按歌手或乐队/组合分类的大封面、推荐、收藏组织内容。
- 每个内容区采用一个标题、一行封面的布局；推荐与收藏的封面比歌手或乐队/组合分类的封面小一些。
- 歌曲封面点击后进入详情页，详情布局归 M02。
- 一行内容过多时采用横向列表，仅通过点击左右交互按钮浏览，不使用鼠标滚轮进行横向切换。
- 收藏为空时不显示首页的收藏栏。
- 首次启动且曲库为空时，首页额外显示导入曲库栏；点击后选择歌曲目录。后续本地 MV 库管理在左侧导航的曲库页进行。
- 具体推荐算法未确定。

### 右侧队列入口

- 草图中的右侧为队列收起状态，点击展开入口后，队列从右侧滑出。
- 展开后采用类似 Spotify 的卡片式设计。
- 队列以覆盖层形式显示在页面内容上方，并通过阴影表达层级。
- 收起时显示待播歌曲数量；队列内部操作和排播规则归 M03。

上述本轮设计确认日期：2026-10-27。主要理由为保持界面简洁、首页留白，以及将开始与返回演唱集中在同一位置。

## 左侧竖向导航

竖向布局、增加首页图标与设置位于底部已确认；搜索、收藏、曲库、创作的入口及用途沿用用户暂定方案。前进、后退控件位于软件左上角，不属于此竖向列表。

| 入口 | 页面用途 |
| --- | --- |
| 首页 | 返回首页 |
| 搜索 | 点击后进入搜索界面 |
| 收藏 | 查看自己收藏的歌曲列表 |
| 曲库 | 管理本地 MV 库 |
| 创作 | 编辑之前录制的演唱歌曲；本模块仅记录入口与页面用途，编辑功能范围尚未定义 |
| 设置 | 入口固定在左侧导航最下方 |
