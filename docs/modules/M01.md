# M01 主界面与首页导航

更新：2026-10-27。设计部分确认；尚未实现。

## 已确认

- 左侧功能导航、中央曲目推荐、右侧队列默认收起，可展开/收起。
- 首页采用本地推荐、最近唱过、常唱与收藏等方向；具体推荐算法未确定。
- 首次使用和空曲库有明确添加入口；浏览与远距离演唱分别考虑字号和信息密度。
- 进入演唱保留形变过渡方向，具体单/双屏呈现归 M04。

## 讨论中

- 用户原设想为中央右下较大的 Material 风格悬浮按钮，后来重新考虑顶部固定位置，尚未选定。
- 用户提案：演唱中从单屏返回选歌时，入口用于进入演唱画面，背景使用当前 MV 的模糊色彩。
- 助手建议（未确认）：顶部固定的当前演唱区配清晰的“返回演唱”文字；模糊画面作背景，图标和文案保持清楚。
- 空队列、待开始、演唱中各状态的入口文案、位置与动作仍待确认。

## 可讨论的小问题

已经有人在唱时，“返回演唱”入口放在哪里，显示哪些信息？协作者可画两张位置对照草图，草图不代表定稿。
