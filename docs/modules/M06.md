# M06 房间与手机点歌

更新：2026-10-28。局域网网页方向及手机端排列预设入口已确认，身份与权限讨论中；尚未实现或验收。

## 已确认

- 手机通过局域网网页点歌，无需专用 App；实际曲库、播放与队列状态保留在电脑。
- 公网中转为后续候选，不作为首版前提；电脑热点是接入候选方式。
- 扫码连接热点与打开网页是两个动作；双二维码只是引导建议，不保证一键自动完成。
- 手机点歌的待播列表提供排列预设入口；模式名称及具体排播规则统一见 [M03](M03.md)，允许谁切换模式仍待权限讨论。“一人一首”基本规则已确认，留到手机点歌阶段实现，当前电脑端由一人集中点歌，不启用按人轮唱。确认日期：2026-10-28；按用户明确要求提供手机端选择列表排列方式的入口并安排轮唱的实现阶段，尚未实现或验收。

## 用户提案（未定稿）

- 加入房间先编辑昵称和头像；人人可点歌，只能删除自己点的歌曲。
- 可替他人点歌，被点者收到提醒，并能删除代点给自己的歌曲。
- 全员可调整队列顺序。

## 助手建议（未确认）

- 区分点歌操作人与演唱者，显示“某某演唱、某某代点”；身份的呈现方式仍为建议，“一人一首”按实际演唱者轮流的规则已确认，统一见 M03。
- 演唱者可删除代点项；操作人是否能撤回、主人是否有全局管理权仍待确定。
- 默认头像可直接使用；代点提醒不遮挡演唱；全员排序可提供操作提示与撤销。

## 可讨论的小问题

小明替小红点歌时，歌曲属于谁、谁能移除？本模块定义身份权限，M03 决定如何据此排播，避免复制两份规则。
