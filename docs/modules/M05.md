# M05 曲目预览

更新：2026-10-27。预览行为尚未定稿、尚未实现。

## 用户提案

- 鼠标在专辑封面停留 3 秒后，放大封面并播放 MV 预览。
- 点击歌曲行右侧的预览按钮，打开可调节进度条的迷你播放器，供详细预览。

## 助手建议（未确认）

- 悬停为静音轻预览，以浮层呈现，不改变歌曲行高度；可关闭，指针移入浮层后保持可见。
- 主动点击才打开带进度、暂停和声音控制的迷你播放器；3 秒时长先在原型中验证。
- 预览不打断、替换或自动压低正在演唱的歌曲。
- 有声试听应明确作用范围；无私密试听条件时，演唱中先保持静音。这条边界尚待用户确认。

## 可讨论的小问题

演唱进行中，悬停预览显示什么，哪些动作必须主动点击？协作者可画轻预览与主动预览两个状态。

范围：预览自己的生命周期、进度与声音；正式演唱归 M04。不要从打开预览推导出改变正式播放或队列。
