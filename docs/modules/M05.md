# M05 曲目预览

更新：2026-10-28。两种预览方式与默认声音规则已明确；控件外观和弹出方式待讨论，尚未实现或验收。

## 已确认的入口与默认行为

- 粗略预览：在搜索结果列表的专辑封面上悬停，在原封面位置放大一部分区域并静音播放 MV。
- 详细预览：用户进入歌曲详情页，点击专辑封面上的悬浮播放图标，呼出预览控件。详情页封面下方保留收藏与加入待播按钮。
- 系统尚未开始卡拉 OK 模式时，详细预览带有声音；系统正在卡拉 OK 模式时，详细预览默认静音。
- 预览控件的 UI 与弹出方式仍待在本模块讨论，不从入口确认推导完整控件设计。

确认日期：2026-10-28。以上为用户在 M02 讨论中明确给出的预览要求，按模块归属整理于此；理由为区分快速浏览和主动详细预览，并在演唱期间默认保持预览静音。以上为设计确认，尚未实现或验收。

## 早期用户提案（尚未确认）

- 封面悬停 3 秒后触发预览；具体时长仍待核对及原型验证。

## 助手建议（未确认）

- 悬停预览不改变歌曲行高度；可关闭，指针移入预览区域后保持可见。具体呈现以用户已明确的原封面位置局部放大为基础继续讨论。
- 详细预览提供进度、暂停和声音控制；具体控件布局及操作尚未确认。
- 预览不打断、替换或自动压低正在演唱的歌曲。
- 若允许在演唱中主动开启预览声音，应明确声音作用范围及与正式演唱的关系；默认静音本身已由用户明确。
