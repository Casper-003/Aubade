# M03 点歌队列与排播

更新：2026-10-27。核心排队目标已确认，细则讨论中；尚未实现。

## 已确认

- 首个完整流程包含找到本地歌曲、加入队列、播放和切下一首。
- 主界面的右侧队列默认隐藏，可展开/收起。

## 用户提案（未定稿）

- 右键菜单插播；重复点歌显示提示，确认后仍可再加入。
- 控制端和手机端可以删除；拖动歌曲右侧手柄排序。
- 提供点歌顺序、一人一首、最新优先（倒序）三种预设。
- 全员可调整顺序；具体歌曲归属和删除权限见 M06。

## 助手建议（未确认）

- 插播明确为“排到下一首”，并保留可见的更多菜单入口；当前歌曲固定，不参与普通重排。
- 重复提示说明已有歌曲的版本、演唱者和位置，而非只说重复。
- 预设是持续规则还是一次性整理尚待决定；建议拖动后显示手动排序，避免自动跳回。
- 一人一首按演唱者计算；新人、新点歌曲与插播的位置尚未定义。

## 可讨论的小问题

已在队列的同一首歌再次被点时，提示什么，确认后放在哪里？身份与代点归 M06；演唱画面的简易队列入口归 M04。
