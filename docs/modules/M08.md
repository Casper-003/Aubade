# M08 音频与演唱控制

更新：2026-10-27。三种模式已确认，控制布局与效果范围待定；尚未实现。

## 已确认

- 保留共享低延迟、独占、兼容共享三种 WASAPI 模式，由用户切换。
- 目标支持普通 USB 麦克风与板载声卡，不以额外专业 ASIO 声卡或手动安装第三方音频驱动为使用前提。
- 具体设备支持范围和总往返延迟须实测，10–18ms 不能写成所有设备的保证。

## 待讨论与验证

### 首轮调试范围（2026-10-28，Casper-003 确认）

- 首先跑通本地电脑端点歌与 MV 播放，再验证麦克风的软件返听与处理。
- 此安排是开发顺序，不取消已确认的三种 WASAPI 模式，也不表示返听、混响、录音的最终范围已经定稿。
- 首轮验收聚焦导入、找歌、入队及播放；不以麦克风采集、音效或低延迟指标作为本轮通过条件。
- 理由：尽快得到可实际调试的完整点歌播放流程，降低同时接入多条音频链路的复杂度。

- 主界面和演唱画面直接暴露哪些人声/伴奏控制，哪些放入设置。
- 返听、混响及其他音效的具体首版范围、文案与默认值。
- 共享低延迟作为默认、切换淡出/重建/淡入、失败恢复和兼容回退仍是实施建议，不能当作已验证能力。
- SDK、音频库、周期设置、跨设备同步与录音对齐尚未确定实现。
