# M07 歌词体验

更新：2026-10-29。体验方向已确认，新增无匹配 MV 时的流光与逐字歌词方向；显示细节与数据接入待定，尚未实现完整演唱歌词。

## 已确认

- 优先评估 Lyricify Lyrics Helper 的 .NET 歌词处理能力，具体集成仍待验证。
- 本地无歌词时可尝试匹配在线来源；保留歌词版本选择、偏移调整和逐行回退。
- 2026-10-29 用户要求详情页歌词也默认自动联网检索，不把搜索和选结果作为普通用户的必经步骤；无法可靠匹配的曲目保留待处理。资料识别按歌名优先、艺人辅助，忽略 Live 等后缀用于找曲目，但不将不同版本时间轴视为相同。
- 不保证任意曲目都有逐字数据，MV、专辑、现场或伴奏版的时间轴不能直接视为一致。
- 2026-10-29 用户要求：以音乐文件识别并匹配 MV，实在找不到时自动呈现流光背景和逐字歌词。逐字歌词需要与实际采用的音频版本对齐，不能直接套用另一个 MV 或现场版的时间轴。无逐字数据时如何满足此目标仍待验证和讨论，不将逐行文本伪装成已获得的逐字时间轴。

## 当前实现（2026-10-29）

- 本轮增加详情歌词预处理：删除 `[id:]`、`[hash:]`、`[sign:]`、`[total:]` 等格式元数据，以及供阅读时不需要的行时间标签；保留正文、正常段落标记和空行。清理同时作用于新获取、既有缓存和本地内嵌歌词的显示，不改原媒体或原始歌词时间轴，避免需要清缓存重搜。

- 本轮扩展：LRCLIB、网易云音乐、酷狗音乐互补检索，任一来源取得经过歌名、艺人与版本核对的歌词即可使用。来源失败不拖垮其他有效结果，保留实际来源；酷狗读取 LRC，不将解码失败或片段时长不符冒充有效歌词。验证记录见[网络检索验证](../网络检索验证.md)。

- 已核对 Lyricify Lyrics Helper 的来源与格式支持，本轮先接入 LRCLIB 公开 API 作为自动歌词源；详情打开时并行查询歌曲资料与歌词，显示纯文本并缓存，断网可继续阅读。
- 校验清理后的歌名与艺人；同名多艺人无充分依据时保留待处理。本地内嵌歌词优先，在线只有 LRC 时去掉时间标签供详情阅读。
- 保留原始逐行数据及来源提供的逐字原始数据，时长和显式 Live 版本标签只用于基础兼容检查，不视为已验证音频内容一致。未通过兼容检查时仍可读正文，不套用其时间轴。
- 已实现取消、请求限速与 Retry-After 等待、失败重试间隔，以及资料修正后旧任务失效；没有生成或伪造逐字时间。
- Lyricify 库正式集成、演唱中的逐字渲染、版本／偏移控件，以及无逐字数据时的演唱呈现仍未完成。来源覆盖不能由两个样本外推到整库。

## 待讨论

- MV 已带歌词时，额外歌词的默认状态与开关。
- 歌词位置、字号、当前/下一句信息和长句的呈现。
- 普通用户如何理解并调整提前/延后，以及调整作用于当前曲目还是全局。
- 无逐字数据、无匹配歌词的界面状态；纯音频无匹配 MV 时已确定流光与逐字歌词方向，具体呈现仍待设计。

## 可讨论的小问题

MV 已带歌词时，额外歌词默认如何显示？协作者可准备远距离观看的短句、长句和逐行排版草图。

技术、歌词格式、来源条件与许可资料见 [参考索引](../参考索引.md)，仅在相关任务中定位查询；开源工具库不等于整个应用或在线词库均可直接套用。
