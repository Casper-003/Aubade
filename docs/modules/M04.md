# M04 演唱画面与本场流程

更新：2026-10-27。显示与过渡方向已确认，结束行为讨论中；尚未实现。

## 已确认

- 单屏进入卡拉 OK 时视频全屏；双屏一屏全屏视频，另一屏保留主界面。
- 用户可指定视频屏幕并记住选择。
- 提前准备播放资源与首帧；单屏展开到全屏，双屏在视频屏完成过渡，控制屏按钮反馈且保留主界面。
- 常规切歌采用轻量反馈；具体动效节奏仍需原型验证。

## 用户提案（未定稿）

- 右侧低可见度简易队列，光标进入右侧时呼出，仅提供队列控制。
- 唱完默认继续；队列播完显示 Logo 和退出本场按钮。

## 助手建议（未确认）

- 常态留可发现的拉手/数量提示；展开后清楚可读，提供点击/键盘与关闭入口，移入面板后保持展开。
- 返回主界面与停止当前演唱分开；队列为空与结束房间分开。
- Logo 等待画面保留继续点歌入口；空队列后新点歌曲是否自动开始、结束本场的影响和权限尚待明确。

## 可讨论的小问题

退出全屏回主界面时，当前演唱和控件状态如何保持？入口位置归 M01，排播规则归 M03，结束权限归 M06。
